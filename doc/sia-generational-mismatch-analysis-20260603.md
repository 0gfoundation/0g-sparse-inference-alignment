# SIA 退化的代际不匹配假设 — VM-Qwen3-4B 跟不上新一代 MoE 主模型

**日期**: 2026-06-03
**起源**: 修复 SIA 实现 (Fix #1+#2+#4 严格对齐官方代码) 后, VL-30B-Instruct 200Q 出现灾难性退化 (人工评分 SIA 6.10 vs noSIA 8.92, 落败 47/50), 远超 Skywork 打分的 -1.6% 表象。需要解释**为什么算法对齐官方却得到相反结果**。

## 2. 假设 — 三个代际不匹配维度

VM-Qwen3-4B 训于 2025-04 的 Qwen3-4B-Base, 时间锚定在 Qwen3 首发。它给"现代"的 30B+ MoE 模型打分时, 出现 **能力代际不匹配**:

### 2.1 能力差距

| LLM | active params / VM ratio | RLHF 强度对比 VM | 评估难度 |
|-----|--------------------------|----------------|---------|
| Qwen3-14B (官方) | 14B / 4B = **3.5×** | 都是 Qwen3 base 后 + RLHF, 同档次 | VM 跟得上 |
| VL-30B-Instruct | 30B 总 / 4B = **7.5×**, 跨模态 RLHF | VL-30B 含 vision 对齐 + 完整 Instruct RLHF | VM 力不从心 |
| 0GM-35B | 35B 总 / 4B = **8.75×**, thinking 强化 | 0GM 含 thinking distillation + 多阶段 RLHF | VM 严重力不从心 |

→ 让一个 4B 的弱 RM 去判断 30B+ MoE 强模型生成的 candidate 谁更好 — **小马拉大车, 必然翻车**。

### 2.2 时间差距 (训练数据 cutoff)

| LLM | 训练 cutoff 估计 | VM 滞后多久 |
|-----|----------------|-----------|
| Qwen3-14B | 2025-04 (与 VM 同期) | **0 月** |
| VL-30B-Instruct | 约 2025-08 | **4 月** |
| 0GM-35B | 约 2025-12 ~ 2026-03 | **8-12+ 月** |

→ VM 对**最近 4-12 个月**新增的知识、表达模式、token 序列都没见过, 评估不可靠。

### 2.3 词表差距

| LLM | 词表大小 | 跟 VM 同词表? |
|-----|---------|--------------|
| Qwen3-14B | 151,936 | ✅ 完全相同 |
| VL-30B-Instruct | 151,936 | ✅ 完全相同 |
| **0GM-35B** | **248,000** | **❌ 跨词表** |

→ 0GM-35B 的 candidate token decode 成文本后再用 VM 词表重新分词时, **可能落到 VM 训练时从未见过的 sub-word 序列** → VM 给出近乎随机的分数。

## 3. 三个实验的 Δ reward 与代际差距高度相关

| 实验 | LLM 能力差距 | 时间差距 | 词表差距 | 实测 Δ reward (Skywork) | 实测 Δ (人工 50题) |
|------|------------|---------|---------|------------------------|------------------|
| 官方 Qwen3-14B (论文报告) | **3.5×** | **0 月** | 无 | **+ (正效果)** | (未公开) |
| **VL-30B-Instruct (我们)** | **7.5×** | **~4 月** | 无 | **-1.6%** | **-32%** (SIA 6.10 vs noSIA 8.92, 落败 47/50) |
| **0GM-35B (我们 805Q)** | **8.75×** | **~8-12 月** | **跨词表 248K vs 151K** | **-13.2%** | (略, 但 Skywork 已显示 -13% 极显著) |

→ **三个差距维度合并越多, Δ reward 越负, 严格单调相关**。这是代际不匹配假设的强证据。

## 4. 为什么"算法对齐官方反而更差"

我们修复后:
- ✅ weight=1.0 (匹配官方)
- ✅ 无 mean-norm (匹配官方 Fix #4)
- ✅ 无 top_p 等二次过滤 (匹配官方 Fix #2)
- ✅ RM 输入末尾无 `<|im_end|>` (匹配官方 ValueModel 训练分布 Fix #1)

但官方的 setup 是 **同代 (Qwen3-14B + VM-4B 同 2025-04)**, VM 信号靠谱; 我们的 setup 是 **跨代 (VL-30B / 0GM-35B vs VM-4B 老一代)**, VM 信号不可靠。

之前未修复时, **mean-norm + top_p=0.95 + RM 输入加 `<|im_end|>` (训练分布外)** 这三个 "bug" 反而**意外起到了 noise dampening 的作用** — 让不可靠的 VM 信号被多重削弱, 看上去像 SIA "没怎么干预", Δ 接近 0。

修复后 VM 信号**真的发力**, 但发力方向是错的 (因为 VM 跟不上主模型代际), 所以输出灾难性退化。

**用一句话总结**: 我们之前的 SIA 是 "用错的算法 × 错的 RM = 接近 0 净影响"; 修复后变成 "对的算法 × 错的 RM = 错的方向放大"。

## 5. 50 题人工评分的典型失败模式 (印证代际假设)

VL-30B SIA-v2 的 50 题人工评分中:

| 失败模式 | 题数 | 解读 (代际假设视角) |
|---------|------|-------------------|
| 严重失控/逻辑断裂 (Q1, Q5, Q17, Q50) | ~10 | VM 偏好"非自然"token → 模型走入 OOD → 后续 step VM 信号更不准 → 正反馈崩溃 |
| 杜撰事实 (Q17, Q25, Q26) | 5 | VM 不知道哪个具体事实可信, 推荐了 plausible-but-false 候选 |
| 中文/泰/希伯来字符注入 (Q15, Q20, Q30, 48...) | ~12 | 这些字符在 VM 词表/训练数据中很罕见, VM 给的分数是噪声 |
| 错误事实 (Q32 "whip bananas", Q33 "Taiwanese dishes") | 3 | VM 错以为这些是合理 candidate |
| 句子戛然而止 (Q1, Q2, Q4, Q18, Q49) | ~6 | VM 偶尔偏好早期 EOS-like candidate |

→ 失败模式高度符合"VM 对 30B 模型的 token 分布认识有限, 给的判断是带偏的噪声"的预期。

## 6. 修复方向 — 解决代际差距才是根本

按代际假设理论, 真正的修复应该匹配 VM 的能力/时间/词表到主模型:

| 优先级 | 方案 | 期望 |
|--------|------|------|
| 🚨 **1** | **用 Qwen3-32B-Base + 自训 LoRA 做 VM** | VM 能力 ≈ VL-30B, 代际接近; 跑 VL-30B SIA 看 Δ 是否回正 |
| **2** | **现成大 RM**: Skywork-Reward-V2-Llama-3.x-8B 直接当 SIA RM | 大 RM (8B) 跟 30B+ 模型差距小, 训练数据更近 |
| **3** | **对 0GM-35B 单独训 VM** (用 0GM 自家 vocab 和 distribution) | 完美匹配 0GM, 词表问题解决 |
| 4 | (短期 mitigation) **降 weight 到 0.2-0.3** | 不解 root cause, 但弱 VM 不再主导 → 输出回到接近 noSIA |
| 5 | **加回 mean-norm** | 削弱大 magnitude RM 信号的极端影响 |
| 6 | (可选) clip rm_deltas 到 ±3 | 直接限制 VM 极端输出影响 |

## 7. 推论 — 论文方法学的隐藏假设

[SIA 原论文](https://arxiv.org/pdf/2602.21215) 的方法学**默认 VM 与主模型同代或更强**。在他们的实验里 (Llama-3.2-1B/3B/8B + Skywork-Reward-V2-Llama-3.x-1B/3B; Qwen3-Xb-Base + VM-Qwen3-Xb-Base), VM 跟主模型**完全同家族同代**, 这个假设隐式满足。

**但论文没明说**: 当 VM 比主模型"老"时, SIA 会反向工作。这是一个潜在的 **未公开的方法学陷阱**。

我们的实验数据 (VL-30B Δ=-1.6%, 0GM-35B Δ=-13.2%) 提供了首个**清晰的代际不匹配反例**。如果验证 Skywork-V2-8B (大 RM, 同 Llama-3.x 同代) 在 VL-30B / 0GM-35B 上能让 Δ 转正, 那就实证了这个假设。

---

## 8. 一句话现状

> SIA 在 VL-30B / 0GM-35B 灾难退化的最佳解释是 **代际不匹配**: VM-Qwen3-4B (2025-04 Qwen3 首发同期训练) 跟不上 VL-30B (2025-秋, 30B MoE, 跨模态) 和 0GM-35B (2026-早期, 35B MoE, 跨词表) 这些新一代强模型, 把一个能力弱、过时、可能跨词表的 RM 信号 (weight=1.0, 严格按官方公式) 强加到主模型, 导致越干预越差。修复方向是**升级 VM** (换大 RM 或同代/同家族 VM), 不是再改 SIA 算法。
